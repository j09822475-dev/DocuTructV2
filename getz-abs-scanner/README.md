# Getz ABS Scanner — диагностика Hyundai Getz через ELM327 (Bluetooth)

Android-приложение для диагностики **Hyundai Getz 1.6 (2006)** через адаптер
**ELM327 Bluetooth (SPP/RFCOMM)**. Основная цель — эмпирический доступ к блоку
ABS; дополнительно — стандартная диагностика двигателя OBD-II.

## Что умеет

1. **Подключение** — к сопряжённому BT-адаптеру (PIN 1234/0000), инициализация ELM327.
2. **Проверка адаптера** (приоритетный модуль) — «годен ли этот ELM327 для ABS
   или это пустой клон»:
   - идентификаторы (`ATI`, `AT@1`, `AT@2`) и напряжение (`ATRV`) — справочно;
   - **полный прогон документированных AT-команд** со счётчиком «поддержано X из N»;
   - **маркерные команды** (`ATPPS`, `ATPP`, `ATAL`) — на них сыпятся подделки;
   - критичные для ABS возможности: ручные заголовки (`ATSH`) и K-line
     протоколы (`ATSP3/4/5`), CAN (`ATSP6`);
   - поведенческие тесты: «мгновенный NO DATA» и обрезание длинных команд;
   - эвристика версии (v1.5/v2.1 — типовые прошивки клонов);
   - итоговый вердикт: **ГОДЕН / УСЛОВНО ГОДЕН / НЕПРИГОДЕН для ABS** + отчёт.
3. **Двигатель (OBD-II)** — чтение (`03`) и сброс (`04`, с подтверждением)
   ошибок, живые параметры (обороты, температура ОЖ, скорость, нагрузка,
   впуск, дроссель), расшифровка частых DTC.
4. **Автоскан модулей** — read-only перебор адресов ЭБУ по K-line
   (KWP fast / KWP 5-baud / ISO 9141-2) с подбором форматного байта заголовка
   (`80/81/C0/C1/82`): по списку кандидатов или полный свип `01–FF`.
   Только команды чтения: `81` (StartCommunication), `1A xx` (идентификация),
   `18/13` (чтение DTC). **Никакой записи и актуаторных тестов.**
5. **Ручной KWP-режим** — свой заголовок + произвольная команда, выбор
   протокола, keep-alive `3E` для удержания сессии.
6. **Лог** — журнал команда→ответ с таймингами, очистка, экспорт в файл/шаринг.

## Сборка

Проект собирается в **Android Studio** (или CI) без правок:

```
getz-abs-scanner/          ← открыть эту папку в Android Studio
./gradlew assembleDebug    ← либо из командной строки (нужен Android SDK)
```

- minSdk 21, targetSdk 34, Kotlin, UI программный (без XML-разметки).
- Зависимости: только `androidx.core-ktx` и `androidx.appcompat`.

Готовый APK также собирает GitHub Actions (см. `.github/workflows/android.yml`)
и публикует в Release `getz-latest`.

## Использование

1. Сопрягите ELM327 в настройках Bluetooth телефона (PIN `1234` или `0000`).
2. В приложении: **Обновить список → выбрать адаптер → Подключиться**.
3. Вставьте адаптер в разъём OBD (под рулём), зажигание — в положение **ON**.
4. **Проверьте адаптер** — если вердикт «НЕПРИГОДЕН», дальше с ABS можно не
   мучиться: сначала другой адаптер.
5. Двигатель: читайте ошибки/параметры — это работает всегда (стандартный OBD-II).
6. ABS: запустите **Автоскан по кандидатам**; если пусто — **полный свип 01–FF**;
   найденные адреса добивайте в **ручном режиме**.

## Честные оговорки

- ABS на Getz 2006 — **не стандартный OBD-II**: блок общается по K-line
  (ISO 9141-2 / KWP2000) по фирменному адресу Hyundai. Проверенных публичных
  команд именно для ABS Getz нет — они в закрытых платных плагинах.
- Поэтому приложение — **инструмент поиска**, а не готовый «читатель ABS»:
  успех зависит от адаптера и от того, совпадут ли перебором
  адрес/протокол/формат заголовка.
- Автоскан шлёт только read-only команды — повредить блок слепым перебором
  нельзя. Сброс ошибок — только вручную и с предупреждением.
- Если перебором связь с ABS поднять не удалось: мультисистемный сканер
  (Launch/Autel) или дилерский GDS/HiScan знают протокол марки.
