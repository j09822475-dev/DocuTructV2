# Ключ подписи APK

`upload.jks` (PKCS12, alias `upload`) — постоянный ключ, которым CI подписывает
каждый релизный APK. Благодаря одному ключу новые сборки устанавливаются
ПОВЕРХ старых как обновление, без удаления приложения.

⚠️ Репозиторий публичный, значит ключ и пароль видны всем. Для личного
приложения это приемлемый компромисс, но при желании усилить защиту:
1. Сгенерируйте свой ключ: `keytool -genkeypair -keystore upload.jks -storetype PKCS12 -alias upload -keyalg RSA -validity 9125`.
2. Закодируйте: `base64 -w0 upload.jks`.
3. Добавьте в GitHub Secrets `KULLER_KEYSTORE_BASE64` и `KULLER_KEYSTORE_PASSWORD` —
   CI автоматически начнёт использовать их вместо этого файла
   (после смены ключа приложение один раз придётся переустановить).

Этот ключ НЕ предназначен для Google Play (там нужен свой, приватный).
