# Eesti keel A2 — уроки эстонского языка (Flutter)

Приложение для изучения эстонского языка по конспекту курса A2.
Один код — **Android и iOS** (Flutter). Никаких игровых механик:
только уроки — слова, тексты, диалоги и тесты.

## Структура

- **Уроки** в хронологии заполнения конспекта (20 уроков): от приветствий
  и знакомства до тем «дом и комнаты», «аренда квартиры», «поликлиника»,
  падежей и послелогов места.
- В каждом уроке:
  - 📇 **Слова** — карточки с переводом, примером и озвучкой (TTS);
    в режиме «перевод скрыт» перевод открывается нажатием на карточку;
  - 📖 **Тексты** — учебные тексты с озвучкой по абзацам и вопросами
    на понимание (ответ открывается по нажатию);
  - 💬 **Диалоги** — чат-пузыри с озвучкой разными голосами собеседников;
  - ✅ **Тест** — 10 вопросов по словам урока (в обе стороны, 4 варианта);
    результат ≥ 80 % засчитывает урок.
- **Прогресс** — пройденные уроки, выученные слова, средний балл
  (хранится локально, без аккаунтов и сети).
- Переключатель «скрыть переводы» в шапке — тренировка восприятия.

Переводы слов и фраз — украинские, как в исходном конспекте курса.
Личные данные из конспекта в приложение не переносились.

## Сборка

CI (GitHub Actions) собирает и публикует в Release `kuller-flutter-latest`:
- `kuller.apk` — Android;
- `kuller-ios-unsigned.ipa` — iOS (неподписанный, ставится через
  Sideloadly/AltStore либо подписывается сертификатом разработчика).

Локально:

```bash
cd kuller_flutter
flutter create . --platforms=android,ios --org ee.kuller --project-name kuller
flutter pub get
flutter build apk --release        # Android
flutter build ios --release        # iOS (нужен Mac + Xcode)
```

Платформенные папки `android/`, `ios/` не хранятся в git — их генерирует
`flutter create .` (см. `.gitignore`).
