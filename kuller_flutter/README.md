# Kuller (Flutter) — эстонский язык для курьеров

Игра-тренажёр эстонского языка для русскоговорящих в виде симулятора курьера
доставки еды. Один код — **Android и iOS** (Flutter).

## Что внутри

- Чат-диалоги на эстонском с переводом и озвучкой (TTS, разные голоса ролей:
  курьер / клиент / ресторан / поддержка).
- Раздельные чаты 🏪 ресторан / 🙋 клиент / 🎧 поддержка с непрочитанными.
- Ветвящиеся диалоги: каждый ответ ведёт к своим последствиям и влияет на
  рейтинг; курьер сам выбирает следующий шаг (граф фаз).
- 20 сценариев, включая негативные: грубый клиент, отказ платить, пьяный
  клиент, собака во дворе, не те блюда — с эскалацией в поддержку.
- Процедурные заказы: рестораны по типам, блюда, имена, адреса, сценарии.
- Разговорник и словарь с озвучкой; скрытие перевода после 20 повторений
  слова; глобальный переключатель «скрыть перевод».
- Прогресс: деньги, XP/уровни, рейтинг, точность (SharedPreferences).

## Сборка

CI (GitHub Actions) собирает всё сам и кладёт в Release `kuller-flutter-latest`:
- `kuller.apk` — Android, ставится сразу;
- `kuller-ios-unsigned.ipa` — iOS, неподписанный: ставится через
  Sideloadly/AltStore (бесплатный Apple ID, переподпись раз в 7 дней) или
  подписывается своим сертификатом разработчика.

Локально:

```bash
cd kuller_flutter
flutter create . --platforms=android,ios --org ee.kuller --project-name kuller
flutter pub get
flutter build apk --release        # Android
flutter build ios --release        # iOS (нужен Mac + Xcode)
```

Платформенные папки `android/`, `ios/` не хранятся в git — их генерирует
`flutter create .` (см. `.gitignore`).
