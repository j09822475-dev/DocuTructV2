# 🛵 Kuller — эстонский язык в виде симулятора курьера

**Kuller** (по-эстонски «курьер») — мобильное приложение для Android, которое
учит **эстонскому языку русскоговорящих** в игровой форме — как симулятор
доставщика еды в духе **Bolt / Wolt**.

Вы играете за курьера в Таллинне: выходите на смену, принимаете заказы и в
каждой доставке проходите живой диалог на эстонском — в ресторане, по дороге и
с клиентом. За правильные ответы получаете €, опыт (XP), рейтинг и чаевые.

---

## ✨ Что внутри

| Экран | Что делает |
|-------|------------|
| **Смена** 🛵 | Дашборд курьера: статус онлайн/офлайн, заработок, рейтинг, уровень и список доступных заказов |
| **Заказ** | Пошаговая доставка-урок: реплика персонажа на эстонском (с озвучкой) → выбор правильного ответа → мгновенная проверка → итог с €/XP |
| **Слова** 🏪 | Словарь по темам: приветствия, еда, напитки, числа, направления, фразы курьера. Прогресс по каждой теме |
| **Разговорник** 📖 | Готовые фразы курьера с переводом и озвучкой (Text-to-Speech) |
| **Профиль** 👤 | Уровень, заработок, рейтинг, точность ответов, выученные слова, прогресс по темам |

### Чему учит
- 👋 **Приветствия** — tere, aitäh, palun, vabandust…
- 🍔 **Еда** — pitsa, burger, supp, kana, leib…
- ☕ **Напитки** — vesi, kohv, tee, mahl…
- 🔢 **Числа** — üks, kaks, kolm … kümme
- 🧭 **Направления** — paremale, vasakule, otse, korrus…
- 🛵 **Фразы курьера** — «Olen kohal», «Kas saate alla tulla?», «Head isu!»…

Озвучка использует системный **Text-to-Speech** с эстонской локалью (`et-EE`).
Если на устройстве нет эстонского голоса — установите его в
*Настройки → Язык → Синтез речи*.

## 🛠 Технологии
- **Kotlin** + **Jetpack Compose** (Material 3)
- Навигация — `navigation-compose`
- Состояние/прогресс — `AndroidViewModel` + `SharedPreferences` (сохраняется между запусками)
- Озвучка — Android `TextToSpeech`
- `minSdk 26` (Android 8.0+), `targetSdk 35`

Контент полностью **оффлайн** и хранится в коде
([`data/Content.kt`](app/src/main/java/ee/kuller/app/data/Content.kt)) —
легко добавлять новые слова и заказы.

## 🚀 Как собрать и запустить

### Вариант A — Android Studio (рекомендуется)
1. Откройте папку `estonian-courier-sim` в **Android Studio** (Koala/Ladybug+).
2. Дайте студии синхронизировать Gradle и скачать Android SDK.
3. Нажмите ▶️ **Run** на эмуляторе или телефоне (с включённой отладкой по USB).

### Вариант B — командная строка
```bash
cd estonian-courier-sim
./gradlew assembleDebug
# APK появится в app/build/outputs/apk/debug/app-debug.apk
```
> Нужны JDK 17+ и переменная `ANDROID_HOME` (или файл `local.properties`
> с `sdk.dir=/путь/к/Android/Sdk`).

### Вариант C — без установки SDK (GitHub Actions)
В репозитории есть workflow [`.github/workflows/android.yml`](../.github/workflows/android.yml),
который при каждом пуше **собирает debug-APK** и кладёт его в *Artifacts*.
Зайдите во вкладку **Actions** → последний запуск → скачайте `kuller-debug-apk`,
перекиньте `.apk` на телефон и установите (разрешив установку из неизвестных источников).

## 🧩 Как добавить свой урок
Откройте `data/Content.kt`:
- новое слово → добавьте `WordEntry(...)` в нужную `Category`;
- новый заказ → добавьте `Order(...)` со списком `DialogueStep`,
  где каждый шаг содержит реплику персонажа и варианты ответа (`Choice`).
